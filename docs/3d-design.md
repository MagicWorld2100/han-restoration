# 三维版本设计

视觉主张：一幅可以进入的青绿山河，日光掠过真实起伏的山脊、连续河谷、林地和带城墙的聚落。使用平滑法线、细密地形、材质颗粒、软阴影与远景雾；不采用像素化或刻意的低多边形平面着色。

内容结构：全屏三维场景是操作主体；顶部显示年代和国力；点选城池后展示相关军情；底部提供军议与国策。行军直接发生在地图上，报告只在行动结算后出现。

交互主张：相机带惯性但可随时控制；点选城池会平滑靠近；进军路线贴合地表，队列、辎重与军旗沿路线移动。减少动态效果时缩短镜头运动与演出，保留可读的结果。

保留：原有规则引擎、统一和交接条件、种子重放与经典版存档。经典版另存为 classic.html。新版使用独立存档键，并把正式 207 年开局与预设资源的北伐教学分开标记。

验收：能够选汉中、选择陇右、检查粮秣和胜算、确认出兵、看到实际三维队列移动，最后得到改变资源和疆域的规则结算。必须实测移动视口、相机、存档、失败、不可负担行动和 WebGL 不可用时的提示。全部运行依赖随本地站点提供。

实现参考：[Three.js 渲染器](https://threejs.org/docs/pages/WebGLRenderer.html)、[OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)、[颜色管理](https://threejs.org/manual/en/color-management.html)。

边界：战略地形是美术化示意，不是地理测绘；行军与战斗表现不构成独立即时战术模拟。教学采用预设资源，不与正式统一挑战混记。
