## 实施内容与兼容性取舍

在 [Pages 响应头配置](../deploy/cloudflare/_headers) 中加入强制执行的 CSP，以及 `X-Frame-Options: DENY`，覆盖三维版、经典版与静态资源。按 [Cloudflare 官方 Headers 配置方式](https://developers.cloudflare.com/pages/configuration/headers/) 随静态包发布，不增加后端。

- 脚本只允许本站；禁止内联脚本、字符串事件处理器与 eval。网络连接只允许本站。
- `frame-ancestors 'none'` 与 `X-Frame-Options: DENY` 禁止页面被嵌入；同时关闭子框架、插件、表单提交、base URL 改写与 Web Worker。
- `media-src 'self' blob:` 保留主题曲和本机文件试听；`img-src 'self' data:` 保留图标和本地生成的战报图片。
- **仅样式**保留 `style-src 'self' 'unsafe-inline'`：当前界面模板、城名位置与动画进度依赖内联样式。没有给脚本添加 `unsafe-inline` 或 `unsafe-eval`，也没有为兼容而放开外站来源。
- 将唯一 HTML 内联 onclick（错误页重新加载）改为外部 bundle 中的事件监听器，并在三维初始化之前绑定。未改游戏规则、存档 schema、音效或用户音乐。

CSP 是纵深防护，不替代输入校验、输出转义和部署账户安全；它也不是“网站绝无漏洞”的证明。HTTP 响应头只覆盖此次 Pages 发布；本地 Python 服务与离线单文件没有此 HTTP 头，不冒充已经同步加固。离线包仍照常重建。
