## 局域网发布

- 本机无线网卡地址为 `LAN_ENDPOINT_LOCAL_ONLY`。
- 3199 已被其他 Python 进程占用，使用当时空闲的 3200。
- systemd 用户临时单元 `han-restoration-lan.service` 为 `active/running`。
- 实际监听地址为 `LAN_ENDPOINT_LOCAL_ONLY`。
- 在本机通过该内网地址请求首页、`engine.js`、`app.js` 和 `style.css`，全部返回 HTTP 200。
- 随后的真实设备访问超时。内核日志确认来自 `LAN_ENDPOINT_LOCAL_ONLY` 到端口 3200 的连接被 `UFW BLOCK` 拦截，不能把本机 HTTP 200 当作发布完成的证据。
- 临时测试 3198，同样被防火墙拦截；已停止 `han-restoration-lan-3198.service`，保留原 3200 服务。
- 现有 3199 服务属于另一个项目，未修改。
- 已在 README 写明仅限本局域网、本机地址与游戏 TCP 端口的放行命令。当前会话无免密 sudo，防火墙规则尚未执行，等待服务器管理员执行后从客户端复验。
