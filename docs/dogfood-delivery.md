# v2.0 用户路线验收与交付

> 历史记录的公开脱敏副本：真实部署地址、部署标识和本机路径未纳入仓库；截图、音频、浏览器档案及原始日志只在私有工作区保存。下文记录的是当时的验收，不代表首次 Source Import 的重新测试；当前范围见 [Source Import](source-import.md)。

## 本次约定

目标是将已有三维战略沙盘按可玩产品交付：第一次打开能开始、能学会并完成出征与治理、能暂停与恢复、能带走进度和分享战报。保留历史规则、经典存档与现有局域网服务；不扩展到公网、多人联机、账号或商业化。

参考之前积累的 `其他项目/docs/04-delivery/DELIVERY-WORKFLOW.md` 中 Candidate / Dogfood / Convergence 原则：固定候选 → 按真实用户路线试用 → 保留负面证据 → 局部修复 → 验证直接相邻流程 → 明确剩余限制后交付。这里借用其证据原则，不引入 其他项目 的部署、账号、GitHub 或生产审批系统。

规则测试、停绘的长流程回归、完整绘制的真实浏览器使用、物理设备与人的审美认可，是不同证据，不能互相替代。测试由同一代理执行，不冒充独立人工验收。

## 交付身份

`release-manifest.json` 记录实际构建所有部署文件和离线文件的 SHA-256；`public/release.json` 可从局域网读取当前版本与指纹。每次源码修复必须重新构建并重新核对，不沿用上一候选的无条件 PASS。

## 用户路线与判据

| 用户任务 | 必须发生 | 不得发生 |
| --- | --- | --- |
| 首次打开、进入教学 | 清楚显示教学预设，能看到并点选三维城郭 | 假加载完成、把教学称为正式成绩 |
| 看军需、暂缓出征 | 路线可见，取消不改变年份、资源与历史 | 预览就扣粮、误触造成决策 |
| 出征、读军报、治理 | 实际队列移动；粮秣和新地稳定由规则结算；教学完成有下一步 | 用静态路线冒充行军、占领立即当作统一 |
| 退出到封面、刷新续玩 | 相同决策和状态可恢复，仍显示正确模式 | 静默回退、重复扣粮 |
| 导出、换入口、导入 | 下载真实文件；导入先校验再确认，正确恢复 | 读取失败却显示成功、未确认覆盖现有局 |
| 分享给朋友 | 正确标记局号、年份与教学／正式；PNG 实际下载 | 假排行榜、把局域网地址说成公网地址 |
| 手机点选、旋转、近看 | 触控有效、面板不遮住核心目标、无横向溢出 | 只把桌面缩小后宣称手机已测试 |
| 存储拒绝、损坏档案、无 WebGL | 可见解释；不冒充保存成功；保留原始档案或经典入口 | 删除坏档、伪造成功、无可恢复路径 |

| 发现 | 处置 |
| --- | --- |

| 测试机使用软件 GPU，精细模式很慢 | 识别软件渲染，首次使用流畅模式并明示；用户可切精细并保存偏好 |

- 主程序 SHA-256：`cea29931bc3d8c129c692f57a42b4c0a59785feb49e130fe3c2c84efd5cb5a10`。
- 三维离线 HTML：722,856 字节，SHA-256 `6a8ad5fb609a72d3592d327e3c22fad5181b7256f694e6749c863c16a7e4b676`。
- 桌面：真实 Chromium，1440 × 900；故障用例为隔离的 1280 × 900 浏览器环境。
- 手机：Chromium 触屏模拟，390 × 844、DPR 2，启用系统「减少动态效果」。不是物理手机或微信内嵌浏览器实测。
- 图形设备：ANGLE / SwiftShader 软件 GPU。当前候选自动使用流畅模式；以下教学保留完整场景绘制，不替换渲染器、不直接注入胜利或国力。

## 同一候选的实际结果

### 第一次玩、学会、进入正式挑战

桌面从封面实际进入教学，查看汉中到陇右路线，取消预览后资源和决策不变；重新确认后观察真实兵卒、军旗与辎重移动，并保存中途截图。战役结算后治理陇右，进入 232 年，控制 4 地、粮 74、陇右稳定 70，历史为 `campaign:long → govern`。

手机再次通过触控从头走完这两项决策；教学结束同时提供「开始正式远略」与「分享这场北伐」。实际点击正式远略并确认后，状态为 `campaign / 207 年 / 荆州一个据点 / 粮 66 / history=[]`，没有沿用教学资源。该流程未发现页面脚本错误。

手机近看自动收起城池面板，实际触摸三维城郭可以重新选中。常规选城镜头中，城市投影中心 Y=317.16，详情面板从 Y=413.22 开始，核心城郭没有被面板压住；未发现横向溢出。

触控复验保留了一条失败证据：从屏幕 `(180,390)` 拖动，相机没有变化。复查 `elementFromPoint` 命中「长安」城名按钮，而非三维画布；因此这次结果是测试选点未执行地图拖动，不记作旋转通过。改从确认是 canvas 的 `(100,600)` 处进行真实触摸事件，镜头由 `[210,580,470]` 变为 `[148.80,554.92,521.03]`；双指外扩使视距从 776.46 降至 577.48，旋转和缩放均有效。没有直接修改相机来制造通过。

桌面实际在菜单将流畅切到精细，当前质量和保存的偏好均为 `fine`；重新选汉中并近看，完成真实精细画面截图，未发现页面脚本错误。此测试证明可切换和显示，不证明软件渲染流畅。

教学完成面板最初截图恰好落在入场动画中途，不能据此判定文字长期透明。等待有限 CSS 动画结束后，面板实测 `opacity=1`，复拍可读。截图测试只结束 CSS 入场动画，不停绘三维场景。

### 真正带走进度与分享

- 完成教学后实际下载 JSON、PNG；退出封面、刷新、续玩，再通过浏览器文件选择器导入该 JSON，确认后仍为 232 年、陇右稳定 70。
- 从刷新后的封面导出，下载内容与游玩中导出的文件逐字节一致，未错误导出用于封面展示的教学初始状态。
- 实际导出的存档：`{"schema":2,"mode":"tutorial","seed":207,"history":["campaign:long","govern"]}`。只保存模式、局号和决策，不接受任意国力注入。
- 下载的实景战报是 1440 × 1000 PNG，明确显示「北伐教学 · 预设开局」、局号 207、232 年和 4/7 地，没有冒充正式成绩。
- LAN HTTP 下自动剪贴板不可用时，实际选中完整 149 字战报，并提示「战报已选中，请长按或按 Ctrl+C 复制」。没有误报「已复制」。
- 通过真实文件选择器导入带 `campaign:north` 非法开局决策及 `grain=99999` 的文件，显示「无法重放这份存档，当前进度没有改变」。当前年份仍为 232，教学两项历史与持久化存档均未改变。

### 不可负担行动与离线使用

手机教学转正式后，实际完成四次开局军议，在 216 年、粮 28 时规划进取汉中。确认出征按钮禁用，明确列出「粮秣至少 37」「军备至少 42」；历史仍只有四项开局决策，页面没有横向溢出。

隔离浏览器先设置为离线，再通过 `file://` 打开当前三维单文件 HTML，显示版本 2.0.0。实际正式开局、采纳第一项议案进入 208 年，刷新并续玩后的完整状态完全相同。整个检查外部 HTTP 请求为 0、页面脚本错误为 0；菜单经典版地址正确指向同目录的 `再出隆中.html`。

### 失败时是否诚实、可恢复

以下是隔离浏览器中的明确故障注入，不代表用户设备曾发生这些故障：

| 注入条件 | 实际结果 |
| --- | --- |
| `Storage.setItem` 抛出 `QuotaExceededError` | 正式局首项决策进入 208 年；页面明确提示保存未成功，持久化值仍为 null；返回封面再续玩，内存状态完全相同；仍能下载含 `i0a` 的有效存档；无页面脚本错误 |
| 自动档案是 `{broken-dogfood-save` | 显示恢复说明；原始字符串未删除，能实际下载备份；用户开始新教学后，原始档保留在 recovery 键，新自动档为有效的 228 年教学 |
| 无法创建 WebGL 上下文 | 显示「山河暂未展开」及具体说明，提供真实 `classic.html` 入口，不停在假加载界面 |

## 自动化与长局证据的边界

最终候选上重新运行 `node tests/engine.test.mjs` 与 `node tests/scenarios.test.mjs`，分别 **11/11、6/6** 通过。覆盖成本、生产与粮耗、联盟失守、制度交接、占领后的稳定要求、可达统一、场景隔离和存档校验。

正式 27 次页面决策、262 年完成统一的长流程，在实现阶段已经运行，详见 [三维版实现验证](3d-verification.md)。其中后 12 次为降低软件 GPU 开销而临时停绘；不能宣称是 27 次全程三维视觉或帧率验证。本轮新增的教学、手机与恢复用户路线未停绘。规则引擎未因本轮易用性修复而改变，最终规则测试仍验证完整统一可达。

## 收敛结论与未覆盖项

本轮按用户任务修复教学下一步、手机构图与存档恢复，再复验相邻流程。前端设计技能用于实际截图后的构图检查；浏览器验收技能用于真实点按、文件下载／选择、触屏与错误分支验证。这里交付的是青绿微缩风格的单人回合战略沙盘，不是照片级开放世界或即时战术游戏。

最终重新执行构建与测试后，候选仍为 `cea29931bc3d8c12`。在上述已测环境与任务范围内，未留下阻断开始、教学、正式决策、续玩或带走存档的问题；可交付本地／局域网单人使用。人的易懂程度和审美认可仍由用户实际试玩决定，不由代理自签为完成。

没有以规则通过冒充人的认可：**真实手机 GPU、微信内嵌浏览器、Safari、物理音频播放与朋友的实际易懂程度尚未单独验收**。测试机软件 GPU 不能给出用户显卡的帧率承诺；没有承诺 60 FPS。无联网账号、云同步、多人、经服务器验证的排行榜或公网部署。反事实历史数值是公开游戏模型，不是历史结论。
