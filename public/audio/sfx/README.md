# 场景音效

默认采用浏览器本地合成的马蹄、行军低频、战鼓和金铁碰撞声，没有联网素材依赖。

如有喜欢的实录素材，可放入此目录，并在 `../config.json` 的 `effects` 中设置对应相对路径：

- `march`：队伍行进或马蹄声，循环片段。
- `battle`：交战环境声，循环片段。
- `departure`：出征鼓／号，一次播放。
- `victory`、`retreat`：得胜／收兵，一次播放。

例如 `"march": "audio/sfx/march.ogg"`。路径相对于游戏首页，不是相对于配置文件。未提供或无法读取的音效会回退到内置合成，游戏结算不受影响。

建议循环片段头尾衔接自然，不自带背景音乐，避免与主音乐争抢。请保留来源与使用许可。
