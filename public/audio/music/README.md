# 背景音乐放置处

本仓库仅保留音乐接口文件名 `theme.mp3`。当前主题曲的公开再分发权在本次 Source Import 中未得到验证或授权，因此该音频文件及其 Base64 内嵌形式均不进入公开仓库。原素材保留于维护者本机，不因项目采用 Apache-2.0 而获得音频再分发权。

相对项目路径：`public/audio/music/theme.mp3`。个人本地使用时只能放入自己有权用于该用途的音频，不得把它误带进公共发布包。

MP3、M4A、OGG、WAV 均可；不是 MP3 时保留真实扩展名，并修改上一级 `config.json` 中的 `music.src`。不要只改后缀假装转换格式。

局域网版：放好文件后刷新页面，在声音设置中开启背景音乐。无需上传到外部服务。

单文件离线版：放好音乐后执行 `npm run build`，构建会将音乐一起嵌入 HTML；文件体积会相应增加。这样的本地生成包不得提交公开仓库。公开副本不内嵌音频，也可在声音设置中选择本机音乐临时试听；提交前执行 `npm run check:distribution` 检查构建产物。

只使用你有权用于本次分享范围的音乐。游戏不会自动下载、购买或向第三方上传音频。
